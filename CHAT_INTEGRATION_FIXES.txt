PATIENT SIDE:
1. Patient opens Triage page
2. Clicks "💬 Chat" button in header
3. ChatPanel opens and polls for conversations
4. Messages display automatically
5. Patient sends message → Doctor gets notification
6. Doctor replies → Patient gets notification

DOCTOR SIDE:
1. Doctor views patient in dashboard
2. Clicks "💬 Open Chat" in patient details
3. ChatPanel opens specific conversation
4. Messages load automatically
5. Doctor sends message → Patient gets notification
6. Patient replies → Doctor gets notification

  "sub": "username",
  "user_id": 123,
  "exp": <timestamp>,
  "iat": <timestamp>
}

Login response includes:
{
  "access_token": "<JWT>",
  "token_type": "bearer",
  "role": "patient|doctor",
  "patientId": "PAT-001",
  "user_id": 123
}
