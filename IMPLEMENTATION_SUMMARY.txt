================================================================================
                          DATABASE SCHEMA
================================================================================

CONVERSATIONS TABLE:
  - id (Primary Key)
  - patient_id (Foreign Key → users.id)
  - doctor_id (Foreign Key → users.id)
  - created_at (Timestamp)
  - updated_at (Timestamp)

MESSAGES TABLE:
  - id (Primary Key)
  - conversation_id (Foreign Key → conversations.id)
  - sender_id (Foreign Key → users.id)
  - content (Message text)
  - timestamp (Datetime)
  - is_read (Boolean: 0 or 1)

================================================================================
                           API EXAMPLES
================================================================================

SEND MESSAGE:
  POST /messages/send
  {
    "content": "How are my vitals?",
    "recipient_id": 2
  }

GET CONVERSATIONS:
  GET /messages/conversations
  Returns: [{id, patient_username, doctor_username, last_message, unread_count}]

GET CONVERSATION MESSAGES:
  GET /messages/conversation/1
  Returns: [{id, content, sender_username, timestamp, is_read}]
